# ヒーローズ・リーグ 2026 セッション「つくりながら考えていること」

airpocket（ヒーローズ・リーグ 2025 MAヒーロー）による HL2026 キックオフ登壇用のページ群。

スライドの代わりに、**1作品＝1ページ（1画面に収まる）** の HTML をブラウザ共有で見せながら進行する。

## 構成

- `index.html` … 表紙。話の3軸と、当日回る作品の一覧
- `works/*.html` … 作品ごとのまとめページ。3軸（実現したかったこと／アイデアの広がり／紹介動画）で構成
- `assets/style.css` … 共通スタイル

## 当日の動線

表紙 → 作品ページ → ProtoPedia の作品ページ → 次の作品ページ …
（ProtoPedia 側から各まとめページへのリンクは本人が設置）

## 編集方法

各作品ページの `TODO` と書かれた箇所を書き換える。
動画は `.video-frame` 内の `.placeholder` を YouTube の iframe に差し替える。
